# نظام تسعير مطبعة ألوان — دليل النقل للاستضافة

الملفات دي نسخة كاملة وشغالة من أداة التسعير، لكن بدل التخزين المؤقت
اللي كان شغال جوه معاينة كلود، دلوقتي البيانات (الإعدادات، الفواتير،
الطلبات) بتتخزن في قاعدة بيانات حقيقية اسمها **Supabase**، والموقع
نفسه هيتنشر على **Vercel** (الاتنين مجانين للحجم بتاعك).

اتبع الخطوات دي بالترتيب. كل خطوة محتاجة منك تكمل اللي قبلها الأول.

---

## الخطوة 1: عمل حساب Supabase وتجهيز قاعدة البيانات

1. روح على https://supabase.com واعمل حساب مجاني (تقدر تدخل بحساب Google).
2. دوس "New Project"، اختار أي اسم (مثلاً `alwan-pricing`)، واختار باسورد
   قوي لقاعدة البيانات واحفظه في مكان آمن.
3. بعد ما المشروع يتجهز (بياخد دقيقة أو اتنين)، روح لتبويب **SQL Editor**
   من القائمة الجانبية.
4. افتح ملف `supabase-setup.sql` الموجود جنب الملف ده، انسخ محتواه كله،
   الصقه في الـ SQL Editor ودوس **Run**. ده هيجهز الجدول اللي هيحفظ فيه
   كل بيانات الأداة.
5. روح لتبويب **Project Settings → API**. هتلاقي فيه قيمتين محتاجهم:
   - **Project URL** (شكلها `https://xxxxx.supabase.co`)
   - **anon public key** (نص طويل تحت "Project API keys")
   احفظهم، هتحتاجهم في الخطوة الجاية.

---

## الخطوة 2: تجربة الأداة على جهازك (اختياري بس مفيد)

لو عندك Node.js مثبت على جهازك:

1. افتح الطرفية (Terminal / Command Prompt) جوه فولدر المشروع.
2. اعمل نسخة من `.env.example` باسم `.env` واملأ فيه القيمتين اللي جبتهم
   من Supabase:
   ```
   VITE_SUPABASE_URL=https://xxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=...
   ```
3. شغّل:
   ```
   npm install
   npm run dev
   ```
4. افتح الرابط اللي هيظهرلك (عادةً `http://localhost:5173`) وجرب الأداة.

لو مش عايز تجرب محلي، متخافش، تقدر تعدي للخطوة الجاية على طول.

---

## الخطوة 3: رفع الكود على GitHub

Vercel بتنشر المواقع من GitHub، فمحتاج ترفع الفولدر ده هناك الأول:

1. اعمل حساب على https://github.com لو مالكش واحد.
2. اعمل "New repository"، سميه مثلاً `alwan-pricing-app`، خليه Private
   (عشان يبقى خاص بيك وبفريقك بس).
3. ارفع الفولدر ده كامل على الريبو ده. أسهل طريقة لو مش متعود على Git:
   من صفحة الريبو دوس "uploading an existing file" واسحب كل الملفات
   (ما عدا فولدر `node_modules` لو موجود عندك من التجربة المحلية).

---

## الخطوة 4: النشر على Vercel

1. روح على https://vercel.com واعمل حساب (سجّل دخول بحساب GitHub بتاعك
   عشان يبقوا مربوطين ببعض تلقائي).
2. دوس **Add New → Project**، واختار الريبو اللي رفعته (`alwan-pricing-app`).
3. Vercel هتكتشف تلقائي إنه مشروع Vite/React ومحتاجش تعديل في إعدادات
   البناء.
4. قبل ما تدوس Deploy، افتح قسم **Environment Variables** وضيف فيه
   نفس القيمتين بتوع Supabase:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. دوس **Deploy**. بعد دقيقة أو اتنين هتاخد رابط شغال (زي
   `alwan-pricing-app.vercel.app`) تقدر تشاركه مع الفريق كله.

---

## بعد كده

- أي تعديل تطلبه مني في الكود، هبعتلك نسخة محدّثة من `App.jsx`، وانت
  بس تستبدل الملف ده في الريبو بتاعك على GitHub — Vercel هتعيد النشر
  تلقائي في ثواني.
- كل الفريق اللي عنده رابط الموقع هيشوف نفس الأسعار والفواتير لحظة
  بلحظة، لأنهم كلهم بيقروا من نفس قاعدة بيانات Supabase.
- لو حبيت دومين خاص بيك (زي `pricing.alwan-print.com`) بدل رابط
  Vercel، تقدر تضيفه من إعدادات المشروع في Vercel مجاناً، وبس هتحتاج
  تشتري الدومين نفسه من أي مكان بيبيع دومينات.
